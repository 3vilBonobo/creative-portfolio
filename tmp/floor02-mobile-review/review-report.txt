Floor 02 mobile redesign — review record
26 November 2026

Implemented scope
Phone-only compact exhibition using the existing usePhoneLayout classifier. Initially shows Nerve Ending once and the first two supporting projects in each category. Preserves the catalogue's editorial order. Each category expands and collapses independently, with counts calculated from the actual data. All 12 projects remain available through a single expansion and selection. Each supporting preview is a semantic button; long descriptions, technologies, demo/source links, credits, and confidentiality disclosures are in the existing shared dialog.

Landscape phones use a compact two-column catalogue over the existing panoramic wall artwork. Portrait has the shared rotation icon and the requested invitation. The existing compact Menu header is enabled for Floor 02 phones; the floating floor bar is hidden on this floor. Tablet and desktop still use ProjectCard and the existing desktop pane rules. No new dependencies, artwork generation, commits, pushes, merges, or deployments.
