# Artwork working area

Authoritative specifications live in [docs/art-production](../docs/art-production/README.md).

- `references/` contains selected existing artwork, masks, saved browser screenshots, current layout measurements and proposed coordinate guides.
- `reference-packages/` contains six ZIPs to supply to the dedicated artwork conversations.
- `staging/` receives future production ZIPs only after commissioning approval.

Everything here is outside `public/` and is not served as replacement site artwork. Reference ZIPs use `-reference-v002.zip`. Future artwork ZIPs use `-production-v002.zip`.

The reference screenshots were captured after the approved structural corrections on 25 November 2026. Layout JSON records the requested browser CSS viewport and the actual JPEG pixel dimensions. The renderer may omit scrollbar/viewport chrome pixels. Full-section images are clipped from full-page captures and are naturally larger than viewport images. Sticky Experience full-section images include its scroll runway, so first/last-record screenshots are supplied separately.
