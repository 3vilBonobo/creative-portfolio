# Incoming production artwork

No commissioned replacement artwork has been placed here.

After owner approval, extract a production package into `<package-id>/v002/`. Keep its manifest, production exports, approved references, previews, alignment instructions and known limitations together. Validate archive paths and reject absolute paths or parent traversal before extraction. Validate dimensions, genuine alpha, registered geometry, file sizes and reference provenance before proposing integration.

Reference ZIPs belong in `../reference-packages/`, not here. Never extract an entire package directly into `public/`.
