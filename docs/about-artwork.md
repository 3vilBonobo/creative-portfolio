# About wall artwork

The desktop `public/about/about-wall.webp` and mobile `public/about/about-wall-mobile.webp`, together with their JPEG fallbacks, are temporary generated environmental artwork based on Irene's supplied `about.png` composition.

The production plate contains no baked text, labels, numbers, icons, buttons, or navigation. All meaningful About content remains HTML. The source was generated with the built-in image-generation tool as a straight-on industrial concrete wall with left-side graphite pipework, an upper-right service lamp, a lower-right plant, a thin cyan conduit, and a quiet central content area.

Replace each WebP/JPEG pair together if final commissioned artwork becomes available. Intrinsic source dimensions: desktop 1956 × 804; mobile 848 × 1855.

`irene-portrait.webp` and its JPEG fallback are optimized from Irene's supplied portrait. The photograph itself is not generatively altered; the layout applies only responsive cropping, tonal treatment, and a soft edge mask.
